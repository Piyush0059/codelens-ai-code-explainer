# 🔍 CodeLens — AI Code Explainer & Debugger

An AI-powered web app that **explains**, **debugs**, and **optimizes** code in multiple programming languages. Built with **Google Gemini API**.


![Languages](https://img.shields.io/badge/Languages-Python%20%7C%20Java%20%7C%20C%2B%2B%20%7C%20JS-orange)

## ✨ Features

- **📖 Explain Mode** — Line-by-line walkthrough, key concepts as tags, and Big O time & space complexity analysis
- **🐞 Debug & Fix Mode** — Bug detection with severity levels and line numbers, complete corrected code, edge cases
- **⚡ Optimize Mode** — Bottleneck identification, optimized code, before/after complexity comparison
- Clean dark-theme developer UI with copyable code blocks
- Sample code loader for instant testing

## 🛠️ Tech Stack

- **Google Gemini API** — AI analysis engine
- **Prompt Engineering** — structured system prompts per analysis mode
- **JavaScript / HTML / CSS** — frontend

## 💡 How It Works

1. Paste your code and select the language
2. Choose a mode: Explain, Debug, or Optimize
3. CodeLens sends a carefully engineered prompt to Gemini and renders structured results
